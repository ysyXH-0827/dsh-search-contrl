# DSH-Search-Contrl 详细文档

主页是精简版：[../README.md](../README.md)。这里是被主页收起的细节。

## 为什么值得装

| 优点 | 具体表现 |
| --- | --- |
| 不预设主题 | 2.x 抓的天天是科技 RSS；3.0 的默认路径是「问主题 → 按主题选源」。你搜足球就只出足球。 |
| 标题你说了算 | 报告标题是模板 `{主题}{类型}｜{日期}`，可改成 `{日期} · {主题}晚报` 之类；设置页有实时预览。 |
| 源是挑过的，不是堆的 | 14 条 RSS 都实测过条目数（IT之家 60 / Electrek 81 / 极客公园 29 …），按主题分配，未知主题不硬凑。 |
| 采集快，且可复跑 | 有界并发（默认 5）+ 源缓存（10 分钟）。7 天窗 14 源实测：冷跑 2.66 s → 热跑 26–28 ms。 |
| 不再白跑 | undici 的 `assert(!this.paused)` 断言会在 socket 回调里炸掉整个进程；进程级兜底 + 45 s 看门狗之后，实测连跑 12 次全部正常收尾，个别源超时会被降级记录而不是丢结果。 |
| 审计不撒谎 | `--audit` 会按你要的窗口逐天列出条数，缺的 5 天就写「缺失」，而不是只看有数据的那几天报「✅ 覆盖正常」。 |
| 设置页和官方一致 | 分区 + 行 + 开关 + 底部保存条，样式走 DSH 设计令牌（`--dsw-alias-*`），并保留历史版本回退。 |
| 离线可测 | 7 套不联网的测试共 94 条断言，`pnpm test` 一把过。 |

## 3.0 有什么不一样

| 变化 | 2.2.x | 3.0 |
| --- | --- | --- |
| 默认主题 | 科技（14 条科技/车 RSS 全量跑） | **无**：先问主题，再按预设选源；没预设时按问题动态发现源 |
| 报告标题 | 技能正文写死「标题必须带科技二字」 | 设置里的模板，占位符 `{主题}` `{类型}` `{日期}` |
| 科技源 | 采集脚本里硬编码 | 移入「科技 / 汽车 / 科学」预设，选到才用 |
| 设置页 | 7 个页签（tdr-tabs 风格） | 官方风格分区 + 行 + 底部保存条，新增「报告标题」分区 |
| 主题表 | 无 | 10 个预设：别名正则、关键词、域名、检索词、RSS、板块 |

升级注意：老设置文件不需要手工迁移，`reportTitle` 缺失会自动补默认模板；`topics` 为空时，第一次「发日报」会先反问你，这是 3.0 的设计；之前写死的「科技」标题不再出现，想要科技报告就建一个「科技」主题（或直接说「AI 日报」，预设会匹配到科技）。

## 搜索源：预设 + 动态发现

- 命中预设：用预设的 `feeds` 抓 RSS，用 `boards` 做板块，用 `queries` 做检索种子。
- 没命中预设：按用户问题动态定。实现在 `lib/dynamic-sources.js`：
  1. 解析问题，去掉「日报/周报/最近 7 天/帮我」等词，留下关键词；
  2. 拼 3 条发现查询：`关键词 最新`、`关键词 发布 公告`、`关键词 官网`；
  3. 跑一轮，统计哪些域名真的答了（排除搜索引擎和百科/词典站），取前 4 个；
  4. 用 `site:域名 关键词` 定向再搜一轮。没答过的域名不进源清单。
- 费用：动态发现全程只走免费 Bing 通道，`provider: bing`、`allowPaidFallback: false`，0 Tavily credit。Tavily 只在用户明确指定或预设流程里、且配置了 Key 时才用；`extract` 需要 Key。

## 设置页逐项说明

路径：**设置 → 搜索控制**。改完点底部的「保存」（有改动时按钮才可用），保存会同时写一份历史快照。

### 报告标题

模板输入框 + 三个占位符按钮 + 实时预览。占位符：`{主题}`、`{类型}`（按窗口自动判断：1 天日报、7 天内周报、更长月报）、`{日期}`。默认 `{主题}{类型}｜{日期}`，上限 120 字符，清空则回落到默认模板。影响范围：技能正文的标题行、`scripts/daily-collect.mjs` 的摘要与归档、`scripts/archive-digest.mjs` 的素材标题，全部用同一份模板。

### 报告输出方式

交付方式：只给文件（写进 `reports/`，聊天里只说路径）、只在聊天中呈现（不落盘）、文件 + 聊天（两份都给，长报告推荐）。排版：`表格`（默认）或 `分条`（适合手机看）。事件密度：`large` / `medium`（默认）/ `small`，对应每个板块最多 6 / 10 / 14 条。

### 主题

字段：名称（报告标题里的 `{主题}`，也是匹配预设的第一依据）、预设（可手工指定，留「自动匹配」则按名称 → 关键词 → 域名依次猜）、关键词（检索词种子）、域名（想只在这些站点里搜时填，不填就用预设的域名表）。右侧开关控制是否参与「自动选择第一个主题」；关掉的主题仍可被点名使用。没配置任何主题时，页面会提示「报告先问主题再检索」。

### 搜索源

| 类型 | 说明 | 需要密钥 |
| --- | --- | --- |
| Bing 免费通道 | 默认可用，走 Bing 的 RSS 输出，条数有限 | 否 |
| Tavily | 有 AI 摘要和更长的正文提取，`searchDepth` 可选 basic / advanced | 是（`tavilyApiKey`） |
| 指定站点 | 把检索限制在某个域名内（等价于 `site:`），适合盯一家媒体或一个公告库 | 否 |

每条源可单独开关；「指定站点」只填域名即可（粘整条 URL 会被自动截成主机名）。

### 博主

粘贴博主主页链接，插件按 15 个平台规则识别（B站 / 微博 / 知乎 / X / YouTube / 抖音 / 快手 / 小红书 / GitHub / Medium / Substack / CSDN / 掘金 / 少数派 / 公众号），自动得出平台与账号句柄。「预览查询」会显示这条链接实际会发出什么查询。博主动态支持一次读多个，可配 `deep` 与 `concurrency`。

### 附带要点与字数

显示原链接（默认开）、显示要点（默认开）、要点字数（微博默认 20 字、B 站默认 50 字，10–200，按 20 字挡位）、B 站平台 AI 总结（默认开，有接口时优先取，取不到再退回要点，空结果不缓存）。

### 登录 Cookie

需要登录态的内容（B 站视频与字幕、微博正文、知乎专栏、小红书笔记、抖音列表、X 推文、YouTube 字幕、GitHub 私有仓库）靠这里的 Cookie 抓。关键 Cookie：B 站 `SESSDATA`、微博 `SUB`、知乎 `z_c0`、小红书 `web_session`、抖音 `sessionid`、X `auth_token`、YouTube `SID` / `SAPISID` / `LOGIN_INFO`、GitHub `user_session`。

用法：点「开始登录」→ 弹出浏览器窗口 → 正常登录一次 → 页面显示「已捕获」→ 关窗口。全程只在本机：Cookie 落在 `~/.dsh/plugin-data/dsh-search-contrl/`，不上传、不写日志；设置页只显示掩码。

### 历史版本

每次保存都会把被替换的那一版存成快照，页面列出时间与摘要。点「回退」即恢复该快照（回退本身也会写一条快照，所以回退也能撤）。快照数量受 `historyLimit` 限制。

## 数据落在哪

| 路径 | 内容 |
| --- | --- |
| `~/.dsh/plugin-data/dsh-search-contrl/settings.json` | 设置 |
| `~/.dsh/plugin-data/dsh-search-contrl/history/` | 历史快照 |
| `~/.dsh/plugin-data/dsh-search-contrl/cache/` | 检索/提取的磁盘缓存（`DSH_SEARCH_CONTRL_NO_DISK_CACHE=1` 可关） |
| `~/.dsh/plugin-data/dsh-search-contrl/cookies*` | 登录态（本机文件） |
| `reports/` | 报告与 `_data/archive/` 快照 |

  settings-api.js    # 本机 HTTP 桥接：describe/save/rollback/preview/cookie
  search-tool.js     # 检索工具 + 内存/磁盘双层缓存

## 设计原则

- **设置是唯一的真相**：技能正文不做假设，先读 `settings.json`。
- **不猜主题**：主题缺失就反问，宁多一句也不出一份跑偏的报告。
- **空则不编**：没有源就说明「无内置 RSS，本次靠检索」；没有板块就平铺候选表。
- **数据留在本机**：Cookie 与缓存只写本机文件，不上传。
- **可测**：所有纯逻辑（标题、预设、动态源、归一化、查询构造）都有离线断言。

## 常见问题（完整版）

**「发日报」却先问我主题？** 3.0 的设计：没有主题就不猜。回答一次后可以顺手存进设置，下次一句话直达。

**标题里出现了「日报」但我想要周报？** `{类型}` 按窗口长度自动判断（1 天 / 7 天内 / 更长），把 `{类型}` 从模板里删掉就不会出现。

**主题匹配到了错的预设？** 在「主题 → 预设」里手工指定，比依赖自动匹配稳。

**输出方式保存后又变回「只给文件」？** 页面会用响应回显校验；如果提示「被正在运行的旧版本服务端丢弃了」，说明 DSH 里跑的还是旧插件，重启即可。

**检索太慢？** 先看是不是开了 Tavily `advanced`；采集侧可以把 `--concurrency` 调到 6–8，Bing 免费通道遇到 429 建议串行复测。

**Cookie 点了没反应？** 确认浏览器能正常登录该站点；企业网络/代理下捕获窗口可能连不上，先关代理再试。
